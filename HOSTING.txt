LITTLE WILLY — NETLIFY WEB EDITION 2.12.2

LIVE SITE
https://little-willy.netlify.app/

This repository is a complete static site. There is no build command, framework, PHP or database. Netlify publishes the repository root according to netlify.toml.

CONNECT WITH GITHUB
1. In Netlify, choose Add new site / Import an existing project.
2. Select GitHub and the swissdogface/little_willy repository.
3. Leave the build command empty.
4. The publish directory is already set to "." by netlify.toml.
5. Deploy the site.

MANUAL NETLIFY DROP
1. Sign in at https://app.netlify.com/.
2. Open https://app.netlify.com/drop.
3. Upload the complete Little-Willy-Netlify-v2.12.2.zip package, or its extracted folder.
4. Keep index.html, _headers and all asset folders together.

UPDATING
Upload or deploy the complete new version so code, graphics, music and cache metadata remain synchronized. After an update, reload the game once. If an installed web app still shows an older version, close it completely and open it again so the new service worker can activate.

LOCAL PREVIEW
Run a static server in the repository root:

    python -m http.server 8080

Then open http://localhost:8080/. Do not rely on double-clicking index.html because browser security rules can block service-worker and audio behaviour.

IMPORTANT
- HTTPS is required for installation and reliable offline caching; Netlify provides it automatically.
- _headers contains the security and update rules and must be deployed.
- Saved progress, settings and scores live in the current browser and are not synchronized between devices.
- The first visit downloads the artwork and soundtrack. Later visits can start from the offline cache.
- Phones should use landscape orientation.
